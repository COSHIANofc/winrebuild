# WinRebuilder

WinRebuilder は、Windows 11 の再セットアップ時にソフトウェアの導入や設定の復元を進める GUI アプリです。公開バージョンは **v.1.0.a-pre2** です。

## インストール

[GitHub Releases](https://github.com/COSHIANofc/winrebuilder/releases) から、次のいずれかをダウンロードしてください。

- **WinRebuilder.zip**: 展開して `WinRebuilder.exe` を起動します。`config.yml` と設定例が同梱されています。
- **WinRebuilder-portable.exe**: 書き込み可能なフォルダーに置いて起動します。初回起動時に `config.yml` がなければ作成します。

Windows 11 x64 向けです。ソフトウェアの導入には winget が必要です。実行前に `config.yml` の内容を確認してください。

## 使い方

左側から「ソフトウェア」「ExplorerPatcher」「設定」「情報」を選びます。ソフトウェア画面で登録内容と状態を確認し、必要な項目を選んでインストールできます。「すべてインストール」では登録済みのソフトウェアを順に導入します。進行状況は画面下部に表示されます。

「設定」画面では `config.yml` の場所を確認して手動で再読み込みできます。レジストリのバックアップを選んで復元することもできます。

## ソフトウェア設定

ソフトウェア画面から winget パッケージを追加・削除できます。追加には正確な Package ID が必要です。画面から削除しても、Windows にインストール済みのアプリはアンインストールされません。

`config.yml` をテキストエディターで編集することもできます。保存後、変更は自動的に画面へ反映されます。反映されない場合は「再読み込み」を押してください。設定に誤りがある場合、画面下部に理由を表示し、直前の有効な設定を使い続けます。ファイルを修正して保存すると再読み込みを試みます。

## winget Package ID の探し方

winget ID を調べる場合は、検索ツール [Winget ID Search](https://winget.coshian.dev) の利用を推奨します。見つけた Package ID を WinRebuilder の追加画面に入力してください。

## ExplorerPatcher

ExplorerPatcher は Windows のシェルを変更するため、ほかのソフトウェアの後にインストールされます。専用画面で有効化し、必要なら ExplorerPatcher の設定を保存した `.reg` ファイルを選んでください。対応する設定だけを検証して読み込みます。設定の適用は画面のボタンから行います。

## 言語とテーマ

初期表示は日本語です。左側のボタンで日本語・英語、およびライト・ダークを切り替えられます。言語の選択は保存されます。テーマは起動時にライトへ戻ります。

## 設定ファイル

`config.yml` が現在の設定です。`config.example.yml` は編集の参考にできる設定例で、自動的には読み込まれません。どちらも実行前に内容を確認してください。GUI から設定を変更すると `config.yml.bak` が作成されます。

## トラブルシューティング

- **winget が見つからない**: Windows の App Installer と winget の状態を確認してください。
- **設定が読み込まれない**: 画面下部のエラーを確認し、`config.yml` を修正して再読み込みしてください。
- **ファイルを保存できない**: EXE と `config.yml` を書き込み可能なフォルダーに置いてください。
- **レジストリの操作に失敗する**: 管理者権限が必要な設定があります。画面下部のエラーを確認してください。
